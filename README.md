# Ella's Glam Studio

Luxury makeup artistry and beauty services for weddings, events, editorial work, and bridal styling in Lagos.

## Overview

This project is a premium beauty studio website for AdornedBy_Ella, featuring service pages, a portfolio, booking flow, contact information, and a luxury visual brand aesthetic.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
